# Skillman — Codeman Skill Catalog

**Background Gremlin Group — Creating Unique Tools for Unique Individuals**

There are 41 standalone installable packages: **40 specialist skills plus [Codemaster](../skills/codemaster/) — the self-contained master skill.** All 40 specialties are complete, standalone packages. Each archive contains one top-level skill folder with `SKILL.md` and all of its referenced documents. Skills are instructions and supporting workflows; they do not install third-party runtimes or provide automatic filesystem, GitHub, or tool access.
