# Codemaster — complete module routing index

This index is a routing map, not a substitute for individual skills. The complete `module-guide.md`, README, and all reference files for every specialist are bundled under `references/modules/`.

On activation: inspect all 40 specialties in this index; consider applicability to the user's request; select applicable full playbooks; apply the universal preservation, integration, and verification gates regardless of specialty. An unrelated specialty can be marked not applicable; do not claim to run 40 separate agents, scans, or tools.
