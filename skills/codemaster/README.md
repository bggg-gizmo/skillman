# Codemaster — all 40 Codeman specialties in one skill

Codemaster is a self-contained master skill that embeds **all 40 public specialty modules** and their reference files. Install [`codemaster.zip`](../../upload-zips/codemaster.zip) to use Codemaster without separately installing the 40 individual skills. For narrowly focused work, individual skill ZIPs remain available.

## Usage

Invoke **Codemaster** for a multi-specialty coding, security, operations, or integration task. Codemaster evaluates all 40 specialties, activates the relevant procedures, and enforces the shared preservation and no-regression policy. It does not literally run 40 separate autonomous agents or provide unavailable tools.

## Included source

- [`SKILL.md`](SKILL.md) — top-level master instructions
- [`references/operating-contract.md`](references/operating-contract.md) — portable shared contract
- [`references/local-configuration.md`](references/local-configuration.md) — optional peer configuration
- [`references/module-index.md`](references/module-index.md) — routing map of all 40 specialties
- [`references/modules/`](references/modules/) — complete standalone source of all 40 skills, including their original reference files

See [Skillmanual](../../SKILLMANUAL.md) for verification and installation. Do not commit personal project configuration or machine paths.
