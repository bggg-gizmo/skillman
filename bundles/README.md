# Skillman — Complete Public Bundle

**Background Gremlin Group — Creating Unique Tools for Unique Individuals**

[`skillman-all-public-skills.zip`](skillman-all-public-skills.zip) is an offline collection archive containing all 41 public skills as source folders, all 41 individual skill ZIPs, the Skillmanual, README, catalog, configuration, and verification scripts. **Do not upload the entire bundle as a single skill.** Extract it and select `upload-zips/codemaster.zip` or individual `codeman-*.zip` files to install.

Only public/sanitized skills belong in this collection. The personalized Codemaster edition is explicitly excluded. See [SKILLMANUAL](../SKILLMANUAL.md).
